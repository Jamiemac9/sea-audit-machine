# sea-audit-machine

Local Next.js workbench for the Seaaudit document suite (WR-01 to WR-22). Resident files stay on this workstation. Reports use `[Client_RP_Name]` and `[Managing_Agent_Name]` unless a project label is edited. Chantry Housing and Best Choice Housing are mock training agents only.

The audit project screen edits records in place, accepts dropped or uploaded files, and can reassign or remove them. Rubric settings stores bespoke questions per project.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
