# sea-audit-machine

Local Next.js workbench for the Seaaudit document suite (WR-01 to WR-22). Files stay on this workstation. Reports use `[Client_RP_Name]` and `[Managing_Agent_Name]`. Chantry Housing and Best Choice Housing are mock training agents only.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
